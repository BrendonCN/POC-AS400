### TC-01 — 附加至已開啟工作階段

| | |
|--|--|
| **REQ** | REQ-01 |
| **前置條件** | 終端機工作階段視窗已開啟。 |
| **步驟** | 1. 依約定方式附加（標題／行程／視窗）。2. 確認取得可用工作階段參考。 |
| **預期結果** | 附加成功；後續動作可針對該工作階段。 |
| **狀態** | |

### TC-02 — 輸入有效憑證並提交

| | |
|--|--|
| **REQ** | REQ-02 |
| **前置條件** | TC-01 通過；登入畫面可見；有效測試帳號可用。 |
| **步驟** | 1. 輸入使用者代號。2. 移至密碼欄。3. 輸入密碼。4. 提交（Enter／AID）。 |
| **預期結果** | 主機接受輸入；流程離開登入畫面朝應用畫面前進。 |
| **狀態** | |

### TC-03 — 登入後驗證主選單

| | |
|--|--|
| **REQ** | REQ-03 |
| **前置條件** | TC-02 以有效憑證完成。 |
| **步驟** | 1. 等待畫面文字包含主選單標示（在逾時內）。2. 記錄通過／失敗。 |
| **預期結果** | 逾時內找到主選單文字 → 通過。 |
| **狀態** | |

### TC-04 — 拒絕空白或無效憑證

| | |
|--|--|
| **REQ** | REQ-04 |
| **前置條件** | TC-01 通過；登入畫面可見。 |
| **步驟** | 1. 以空白使用者／密碼**或**無效憑證提交。2. 嘗試主選單驗證。 |
| **預期結果** | 停留登入或錯誤畫面；不顯示主選單 → 觀察到拒絕即為案例通過。 |
| **狀態** | |

### TC-05 — 主選單等待逾時應失敗

| | |
|--|--|
| **REQ** | REQ-05 |
| **前置條件** | 已附加工作階段；主機無法及時顯示主選單（替身／阻擋）。 |
| **步驟** | 1. 以較短逾時觸發「等待主選單」。2. 觀察結果。 |
| **預期結果** | 逾時／失敗；不得誤判通過。等待之後的成功路徑步驟不應繼續。 |
| **狀態** | |

### TC-06 — 工作階段關閉時中止

| | |
|--|--|
| **REQ** | REQ-06 |
| **前置條件** | 流程進行中工作階段仍可用。 |
| **步驟** | 1. 關閉或結束終端機視窗。2. 再嘗試動作（點擊／輸入／等待）。 |
| **預期結果** | 流程中止；不得對已失效工作階段繼續成功執行動作。 |
| **狀態** | |
